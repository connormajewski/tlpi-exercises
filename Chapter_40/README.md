# 40: Login Accounting
### **Exercise 40-1**
Implement *getlogin*. As noted in Section 40.5, *getlogin()* may not work correctly for processes running under some software terminal emulators; in that case, test from a virtual console instead.
### **Exercise 40-3**
Read the manual pages for *login(3)*, *logout(3)*, and *logwtmp(3)*. Implement these functions.
### **Exercise 40-4**
Implement a simple version of *who(1)*.
